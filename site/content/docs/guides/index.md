Each one is a focused recipe for a single job, assuming you already know the
basics from the [tutorial](/docs/getting-started).

- [Add Straitjacket to CI](/docs/guides/ci) — Run it on every push with the bundled GitHub Action.
- [Suppress a false positive](/docs/guides/suppressing-findings) — Silence a finding on one line or across a whole file.
- [Exclude big or generated files](/docs/guides/ignoring-files) — Keep generated output and vendored code out of the scan.
- [Tune or disable rules](/docs/guides/tuning-rules) — Run a subset, adjust thresholds, change the output.
